# Support

- **A question or a bug:** open an issue. The form asks for what makes a report
  quick to act on: `syg version`, the platform, how you installed Syg, the
  command and the smallest module that shows it. The
  [documentation](https://syg.vishisht.tech) and `syg explain NAME` answer
  most questions about a finding, offline.
- **A vulnerability:** report it privately, as [SECURITY.md](SECURITY.md)
  says, never in an issue.
- **What to expect:** issues are answered as time allows, with no guaranteed
  response time. A vulnerability report comes first, with the response times
  [SECURITY.md](SECURITY.md#what-you-can-expect-from-us) sets. The latest
  release is the supported one.

More on the [support](https://syg.vishisht.tech/support.html) page.
